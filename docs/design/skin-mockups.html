Chronos Earth — four visual identities

The same three fragments of the app — the masthead, the Layers panel, the timeline, and the Black Death dossier — dressed four different ways. The globe itself never changes; only the chrome around it. Fonts here are system stand-ins; the real build would self-host proper open-licence faces (free, zero running cost). Pick one as the ship's true colours — the others can become optional skins.
