## Checked and fine

- No empty `catch` blocks — every swallowed error carries a comment saying why.
- Data lint passes; no events with bad coordinates, future dates or end-before-start.
- No console errors on load, in any ⋯-menu panel, or during playback.

## Left as they are, on purpose

- **Small helpers repeated across scripts** (`sleep` ×19, `runQuery` ×8,
  `parseCoord` ×5). The query functions differ in retry and method (GET/POST)
  for reasons recorded in each; merging them would risk the harvest for little
  gain. `pointInRing`/`ringArea` exist in both `src` (TypeScript) and `scripts`
  (plain Node) because the two cannot import each other.
- **One-off data tools nothing runs** (`enrich-battles`, `fetch-treaty-events`,
  `webp-images`): they built data once and are kept so it can be rebuilt.
- **An intermittent multi-minute stall during playback** — the graphics driver
  compiling globe shaders (pausing the JS engine showed no script running).
  Cesium behaviour; watch for it on the Captain's machines.
